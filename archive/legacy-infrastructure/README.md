# Historical infrastructure

These Docker and Jenkins definitions document the former ECS deployment. They are not used by the anniversary app. The active Jenkins entry points are deliberately inert so a code push cannot recreate `hujia.dliu.com` or trigger the old infrastructure.

The current application uses the root `lib/hujia-stack.ts` stack and `jh.dliu.com` only. The old first-gift presentation is retained separately under `archive/first-gift/`; its portrait is private media rather than a public code asset.
